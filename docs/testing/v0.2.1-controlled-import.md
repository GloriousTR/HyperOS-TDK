# v0.2.1 Controlled Import — Device Test Plan

This is the first milestone that invokes Theme Manager's private MTZ import queue. It is not a read-only probe.

## Preconditions

- HyperOS TDK module enabled in the modern Xposed framework.
- Scope includes only `com.android.thememanager`.
- Theme Manager has been force-stopped/restarted after installing v0.2.1.
- Vector/LSPosed log contains `CONTROLLED IMPORT BRIDGE READY` before sending a request.
- Test MTZ is stored under `/storage/emulated/0/` (Downloads is recommended).

## Steps

1. Open HyperOS TDK v0.2.1.
2. Tap `1. Tema Yöneticisini Aç` and allow Theme Manager to finish starting.
3. Return to HyperOS TDK.
4. Tap `2. MTZ Seç` and choose the known test MTZ.
5. Confirm that the displayed path begins with `/storage/emulated/0/`.
6. Tap `3. Kontrollü Import Başlat`.
7. Read the warning and tap `Import Et` only when ready.
8. Wait several seconds and inspect Theme Manager/local themes.
9. Export Vector/LSPosed logs.

## Expected log sequence

```text
CONTROLLED IMPORT BRIDGE READY
CONTROLLED IMPORT REQUEST accepted
CONTROLLED IMPORT invoking ThemeImportManager.v(...)
CONTROLLED IMPORT queued successfully
[IMPORT EVENT] ... action=action_resource_import_start
[IMPORT EVENT] ... action=action_resource_import_complete
```

A `fail` event is also a useful result for this first device test and should be reported with the surrounding Theme Manager logs.

## Stop conditions

Do not repeatedly press the import button after a crash or failure. Export the first-run framework log before retrying so the original error path is preserved.
